# 第二階段執行規劃：整合儀表板

> 2026-11-13 更新：已依本規劃完成，成品與 Claude Code 操作說明見「第二階段組合包」。與規劃不同的一點：索引改存成 index.js，直接雙擊 HTML 就能用，不必開本機伺服器。

日期：2026-11-12
對應：TEJ 簡報第 24 頁、11/20 目標

## 一、要做到什麼

TEJ 的要求是：對 AI 說「幫我在桌面建立整合儀表板」，桌面就出現一個資料夾，裡面有 `整合儀表板.html`、一個啟動程式和 `data/` 資料夾。打開後左側選單依「公司 → 年份 → 場次」切換，之後每跑一場新的法說會，就自動加進去。

## 二、為什麼要用 Claude Code（或 Claude Cowork）

| 需要的能力 | claude.ai 網頁版 | Claude Code／Cowork |
|---|---|---|
| 寫入使用者電腦的桌面 | 不行，只能在雲端環境產生檔案再下載 | 可以 |
| 每次跑完自動更新同一個資料夾 | 不行，每次都要手動下載、整理 | 可以 |
| 執行啟動程式、開本機伺服器 | 不行 | 可以 |

需要啟動程式的原因：瀏覽器基於安全限制，不允許直接雙擊打開的網頁去讀取同一個資料夾裡的其他檔案。所以要先在本機開一個小伺服器，網頁才讀得到 `data/` 裡的每一場。

## 三、執行路徑

1. **安裝 skill**：把 skill 資料夾放進 Claude Code 的 skills 位置，指令與單場流程完全沿用第一階段
2. **單場產出時多存一份資料**：每場除了 HTML，另存 `data/{股票代號}/{日期}.json`。用日期而不用季別命名，因為順達這種重複收錄的情況會出現兩場同一季
3. **建立索引**：新增 `build_index.py`，掃描 `data/` 產生 `index.json`（公司、年份、場次、日期、標題）
4. **整合儀表板**：`整合儀表板.html` 讀 `index.json` 畫左側選單，點哪一場就載入那一場的資料，右側沿用第一階段的互動版版型
5. **啟動程式**：Windows 用 `啟動整合儀表板.bat`、macOS 用 `啟動整合儀表板.command`，內容都是開本機伺服器並打開瀏覽器
6. **自動更新**：skill 規則加一條：在 Claude Code 中跑完單場後，若桌面已有整合儀表板，就把新場次存進 `data/` 並重建索引

## 四、這比單場儀表板多了什麼

單場儀表板回答「這場說了什麼」，整合儀表板可以回答「這家公司的說法怎麼變」：

- **指引追蹤**：同一家公司的指引按季排成一條線，例如台積電全年成長 30% 以上 → 略高於 40% → 約 44%，一眼看出持續上修
- **說話算不算話**：上一季給的財測，對照這一季公布的實際數字，累積幾季就是指引可信度
- **語調趨勢**：講稿和 Q&A 的語調分數逐季畫成折線，看管理層是越來越有信心還是越來越保守
- **議題變化**：哪些關鍵字這季突然出現、哪些消失了

這些功能只需要已經存好的各場資料，不必重新讀逐字稿。

## 五、怎麼驗證

| 驗證項目 | 做法 | 通過標準 |
|---|---|---|
| 一鍵建立 | 在 Claude Code 說「幫我在桌面建立整合儀表板」 | 桌面出現資料夾，雙擊啟動程式就能打開 |
| 選單層級 | 把案例集 16 場全部灌入 | 公司、年份、場次三層都正確，台積電有 Q2、Q3 兩場 |
| 新增場次 | 再跑一場新的法說會 | 不用手動操作就出現在選單 |
| 重複收錄 | 灌入順達兩場 | 兩場都在，並標示疑似重複 |
| 跨季比較 | 打開台積電 | 指引追蹤顯示 Q2 → Q3 的上修 |
| 離線 | 拔掉網路 | 一樣能打開、切換 |
| 跨平台 | Windows 與 macOS 各試一次 | 啟動程式都能用 |

## 六、要先和 TEJ 確認的事

1. 展示時用 Claude Code 還是 Claude Cowork，以及 TEJ 的電腦是 Windows 還是 macOS
2. 跨季比較算不算在 11/20 的範圍，或是放到 11/27 的成果展示
3. 如果展示環境沒辦法裝 Claude Code，備案是在 claude.ai 先做好整個資料夾、壓成 zip 下載，解壓縮後一樣能用，只是少了「自動更新」
