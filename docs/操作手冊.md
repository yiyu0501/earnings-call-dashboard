## 1. 第一次設定

需要：Git、Python 3.10 以上。要跑網站測試或重建台積電地圖，另外需要 Node.js。

```bash
git clone https://github.com/yiyu0501/earnings-call-dashboard.git
cd earnings-call-dashboard
pip install openpyxl pdfplumber python-docx   # 讀 TEJ xlsx、PDF、Word 逐字稿
```

## 2. 本機預覽與測試

```bash
python -m http.server 8000
```

瀏覽 http://localhost:8000/。直接雙擊 `index.html` 也能看大部分內容，但台積電經濟體與 3D 主視覺要用上面的方式才完整。

**每次改完都要做的兩件事：**

```bash
cmp index.html skill/earnings-call-dashboard/assets/integrated_template.html   # 沒有輸出代表一致
python integrate.py --target . --site --check                                  # 檢查 data/ 並重建 index.js
```

**網站自動回歸測試**（改版面後建議跑）：

```bash
npm i playwright && npx playwright install chromium   # 第一次
node tools/site_test.js                                # 顯示 ALL PASS 即通過
```

偶爾會出現一次 iframe 的 `reqfail`，是切換太快造成的，重跑一次即可。

## 3. 新增一場法說會

1. **產生儀表板**：在 Claude（Claude Code、Cowork 或 claude.ai）安裝 skill 後，上傳逐字稿並說「幫我做這場法說會的儀表板」。skill 會依 `SKILL.md` 讀檔、撰寫、計分、檢查，直到通過。
2. **輸出公開版**（網站只能放公開版）：
   ```bash
   python skill/earnings-call-dashboard/scripts/render_motion.py WORK/dashboard.json \
       --tone WORK/tone.json --keywords WORK/keywords.json --transcript WORK/transcript.json \
       --public --outdir WORK/out_public
   ```
3. **加入網站**：
   ```bash
   python integrate.py --target . --site --add WORK/out_public
   python integrate.py --target . --site --check
   ```
   檔名自動取「公司_日期.html」，同一場再加一次會覆蓋。
4. **發布**：見第 7 節。

也可以直接在 GitHub 網頁上把公開版 HTML 上傳到 `data/`，GitHub Actions 會自動重建網站。

**升級成焦點公司**（像台積電）：產生時把 `meta.deep` 設為 `true` 並補齊深度欄位，至少兩場；細節見交接說明第 3 節。

## 4. 更新行事曆

1. 從 TEJ 逐字稿資料庫匯出最新的 xlsx。
2. 執行：
   ```bash
   python tools/build_universe.py <TEJ 逐字稿 xlsx> universe.js
   ```
3. 產業與指標公司在 `tools/build_universe.py` 的 `INDUSTRIES` 修改。
4. 發布。

## 5. 修改網站版面與文字

- **只改模板**：`skill/earnings-call-dashboard/assets/integrated_template.html`，改完執行
  ```bash
  cp skill/earnings-call-dashboard/assets/integrated_template.html index.html
  ```
  不要直接改 `index.html`，下次複製時會被蓋掉。
- **首頁區塊、焦點公司、市場共識、小額支持**等設定集中在模板 `<script>` 開頭的 `SITE` 物件，各欄位說明見交接說明第 3 節。
- **顏色與字級**只用 CSS 變數（`--primary`、`--navy`、`--line` 等），深色模式會自動跟著變。
- **頁首與頁尾文字**：搜尋模板中的 `siteFoot`（頁尾）與 `class="brand"`（頁首）。
- **分享預覽**：分享圖是根目錄的 `og.jpg`（1200×630），網址寫在模板 `<head>` 的 `og:url`、`og:image`、`canonical`。換網域時三者都要改。

## 6. 更新台積電經濟體

台積電經濟體是單一檔案 `tsmc/index.html`，資料全部內嵌，由 `tools/tsmc_economy/` 重建：

```bash
cd tools/tsmc_economy
npm install          # 第一次
python words.py      # 有新一季逐字稿時才需要：從 txt/ 的逐字稿算詞頻（逐字稿原文不放進儲存庫）
node geo.mjs         # 產生地圖與足跡座標（新增足跡事件時改 data/tsmc_footprint.csv）
python mk.py         # 把 tpl.html 和資料組成頁面，直接寫入 tsmc/index.html
```

- 改文字或樣式：改 `tools/tsmc_economy/tpl.html`，再執行 `node geo.mjs` 與 `python mk.py`。
- 新一季財務數字：改 `data/tsmc_quarterly.csv`、`tsmc_annual.csv`，再轉成 `fin.json`（轉換程式未收進儲存庫，可請 Claude 依 CSV 重新產生）。
- 詳細說明見 [`tools/tsmc_economy/README.md`](../tools/tsmc_economy/README.md)。

## 7. 發布到網站

```bash
git add -A
git commit -m "說明這次改了什麼"
git push origin main
```

推送後 GitHub Actions 會先執行 `integrate.py --check`，通過才發布；約 1–2 分鐘後網站更新。到 GitHub 的 **Actions** 分頁可看到每次發布是否成功（綠勾）。

> Cowork 目前不能執行 `git push`，請在自己電腦的終端機推送。

## 8. 出問題時

| 狀況 | 處理 |
|---|---|
| Actions 顯示紅叉 | 點進去看哪一步失敗。最常見是 `data/` 裡有完整版 HTML，改放公開版 |
| 網站沒更新 | 等 2 分鐘後強制重新整理（Mac：Cmd+Shift+R）；確認 Actions 是綠勾 |
| 想回到上一版 | `git revert HEAD` 後推送，會新增一個「還原」的 commit，不會刪掉紀錄 |
| git 顯示 `File exists`、`.lock` | 確認沒有其他 git 正在執行，把 `.git/` 裡的 `*.lock` 刪除或改名 |
| 首頁 3D 沒出現 | 正常：窄螢幕、不支援 WebGL、開了「減少動態效果」時會顯示 2D 版本 |
| 某頁顯示「找不到這一頁」 | 網址的公司代號或場次不存在；檢查 `data/` 檔名與 `index.js` |
| LINE 預覽還是舊的 | LINE、Facebook 會暫存預覽，過一段時間才更新 |

## 9. 每季例行工作

財報季（約 1、4、7、10 月中旬起）：

- [ ] 匯出 TEJ 逐字稿 xlsx，更新行事曆（第 4 節）
- [ ] 指標公司的新法說會產生儀表板，輸出公開版加入網站（第 3 節）
- [ ] 台積電新一季：做深度儀表板，並更新台積電經濟體（第 6 節）

## 10. 維護 GitHub 作品集

**一次性設定（在 GitHub 網頁操作）**

1. 儲存庫首頁右側 **About** 旁的齒輪：
   - Description：`臺灣上市櫃公司法說會儀表板與 Claude Skill｜台灣經濟新報（TEJ）實習專案`
   - Website：勾選「Use your GitHub Pages website」
   - Topics：`earnings-call`、`claude-skill`、`dashboard`、`taiwan-stock`、`data-visualization`、`github-pages`
2. 個人首頁 → **Customize your pins**，把這個儲存庫釘選在最前面。
3. 可以在個人首頁 README（`yiyu0501/yiyu0501` 儲存庫）放上網站連結與一句話介紹。

**發布版本（建議 12/4 展示前做一次）**

```bash
git tag -a v1.0.0 -m "法說會大平台 1.0：12/4 展示版"
git push origin v1.0.0
```

再到 GitHub 的 **Releases → Draft a new release**，選 `v1.0.0`，貼上 `CHANGELOG.md` 對應段落，並附上 `dist/earnings-call-dashboard.skill` 與 `docs/一頁簡介.pdf`。之後有大改版就發 `v1.1.0`、`v2.0.0`。

**日常維護**

- 每次推送都寫清楚的 commit 訊息（現在的寫法就很好：一句話說改了什麼）。
- 每個版本在 `CHANGELOG.md` 記一筆。
- `.github/dependabot.yml` 會每月檢查 GitHub Actions 有沒有新版本並開 PR；看過變更說明、Actions 通過後再合併。
- 不要上傳逐字稿原文、TEJ 原始 xlsx、API 金鑰。
- **授權**：目前沒有放開源授權（LICENSE），代表別人可以看但不能自由使用。這是 TEJ 實習成果，要不要開源、用哪種授權，請先問 TEJ。

## 11. 安裝 skill

打包好的 skill 在 `dist/earnings-call-dashboard.skill`。

- **Claude（claude.ai、Cowork）**：設定 → Capabilities／Skills → 上傳 `.skill` 檔。
- **Claude Code**：把 `skill/earnings-call-dashboard/` 整個資料夾複製到 `~/.claude/skills/`。

修改 skill 後重新打包：

```bash
python tools/make_zip.py skill/earnings-call-dashboard dist/earnings-call-dashboard.skill
```
