## 第 4 輪　解決四個痛點

**我的要求**
- 「內容帶不走」是最大的問題；我會需要 100 到 300 字的稿，複製下來小改一下就貼給同事
- 原文沒有上下文、上修沒有數字也要處理；英文不用翻譯，「看不懂英文就問 AI」

**決定**
- 首頁直接列出這場的修正項目與前後數字
- 從上一場逐字稿找出原句，補上「前次數值」，並附「上一場原文」按鈕
- 把兩場逐字稿包進頁面，每句原文都能「看上下文」並跳到原處標黃（48 句全部定位成功）
- 新增「報告稿」：LINE 同步、組內摘要、研報重點三種現成的稿，以及從卡片挑選組成的「自己挑」；指引表可整張複製到 Excel

## 第 5 輪　細節修正與透明度

**我的要求**
- 上修的樣式像按鈕，改成台股慣例：上修紅、下修綠，加小走勢線
- 「mid-to-high 50s」是什麼？是失誤嗎
- 報告稿要有依時間變化的問候語，LINE 同步用條列，組內摘要先總結再條列
- 「我挑的」看不懂怎麼用

- 要不要依重要性給語調詞加權

**決定**

- 主持人點名時會說出姓名與券商，22 題都對上提問者；逐字稿沒提到的照實標「未提及」，不猜

## 第 9 輪　副標題的語氣

**我的要求**
- 「沒有上修或下修，以下為維持不變的指引」——你真的有上一場的數據嗎？副標題可以用比較正式、像論文的語氣
- 卡片上的「由 58 天下降至 33 天」不用重複大字已經寫的數字

**決定**
- 儒鴻那三項「維持」，上一場確實沒有可對照的數字，是依本場管理層的說法判斷；副標題改為寫明比較基準與判斷依據，例如「比較基準：2026-05-19 法說會。本場未見上修或下修；下列指引判定為維持，惟前次未揭露可對照之數值，係依本場管理層陳述判定。」
- 正式語氣用在說明資料的副標題；操作提示維持白話
- 資料仍存完整的「由 58 天下降至 33 天」，只有卡片顯示時省略與大字重複的部分，規則與檢查不受影響

## 第 15 輪　做成網站

**決定**

**過程中發現**：先前的 GitHub 上傳包裡，範例與案例的 HTML 是完整版，內含完整逐字稿 → 新的儲存庫全部改用公開版，並用程式檢查 19 個 HTML 都沒有夾帶逐字稿

## 第 16 輪　讓網站好用、靠得住

**我的要求**
- 老師同意公開。這個 skill 離好用、靠譜的網頁還有一段距離，請幫我開發

## 第 17 輪　確定網站的定位

**我的問題**
- 「產生交給 Claude、網站負責瀏覽」是不是表示開發者不用付錢？

**釐清**
- 是。產生儀表板在 Claude 裡完成（claude.ai 或 Claude Code），用的是產生者自己的 Claude 方案，不需要 API 金鑰或伺服器；網站只負責瀏覽、搜尋、比較，訪客免費、不需要 Claude 帳號
- 網站本身不提供「上傳逐字稿自動產生」。若要讓訪客自己產生，必須另架伺服器並付 API 費用（選項 B），或改在 claude.ai 裡做（選項 C），但 C 無法執行 skill 的檢查程式，品質較差

## 第 32 輪　雲霄飛車自由旋轉與真實物理（2026-11-18）

**我的要求**
- 車子看起來不太對勁；標誌還不能 360 度轉；不要下面的圓盤，想要像球體一樣轉
- 物理引擎要真實，可以多用運算

**決定**
- **旋轉**：拿掉圓盤與外環。標誌與軌道放進以中央為軸心的群組，拖曳空白處依拖曳方向繞畫面座標軸旋轉，不設角度上限；放手保留慣性並逐漸減速。閒置 7 秒後慢慢轉回原本的正面角度，讓首頁平常維持正常運行
- **重力**：永遠朝畫面下方（以旋轉後的座標換算），把標誌倒過來，車子就往另一邊跑
- **軌道上的物理**：三節車廂分別計算重力分量；滾動阻力隨正向力變化（重力垂直分量加上彎道向心力）；另加空氣阻力。爬升段改為剛性鏈條（不低於 2.4）；加速段為驅動輪；停住超過 3 秒時由驅動輪推至下一段爬升（真實雲霄飛車也有）。移除舊版「最低速度」的人為設定
- **抓起與甩出**：三節車廂改為以連桿相連的質點，以 Verlet 積分（每格畫面 8 個子步）計算重力與空氣阻力；抓住時車頭以強彈簧跟隨指標。放手後若車頭落到距軌道 0.22 以內就重新上軌（沿軌道速度取甩出速度的切線分量），飛離中心超過 14 則從車站上方放回。最近軌道點以 0.6 單位的空間格子查詢
- **軌道調整**：為了在正放時能跑完全程，爬升頂點加高（標誌圖座標 y −25）、右端轉彎改為下降 1 單位、回程支柱高度縮為 3.0 至 4.4、起點略降。正放時一圈約 9.2 秒，最低車速約 0.6
- **車廂**：上輪與防脫輪夾住兩條鋼軌，車斗兩排座位各坐兩位乘客（頭、上身），有安全桿；車頭為方錐形鼻錐加車燈
- **金幣**：沒有地面後改為順著重力落下、翻轉、淡出

**驗證**：無頭 Chromium 模擬正放 60 秒共 6 圈，未觸發驅動輪救援；倒置時車子依反向重力運動；四個角度截圖（正面、側面、斜上、倒置）與車廂特寫確認外觀；平面版（600px）軌道同步更新；`tools/site_test.js` 全數通過；`integrate.py --check` 通過，`index.html` 與模板一致。
