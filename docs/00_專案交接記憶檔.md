## 2. 我的工作方式（請照做）

- **直接做出成品給我看，不要先跟我討論選項。** 討論我很難判斷，看到成品比較好決定。
- **在意 token 用量。** 確認方向時用省 token 的方式；大量蒐集資料可以寫 prompt 讓我交給 ChatGPT 做。
- **推送前先問我。** 我有時會說「之後一併推就好」，就先只在本機 commit。
- **文字風格**：網站上的說明文字用書面、正式、像論文的語氣；操作提示用白話。不要寫得太長。
- **不要有「AI 感」**：數字不要一直跳動、介面不要花俏卻沒意義；但「沒什麼用但很帥」的小互動我喜歡。
- 我不是分析師，對分析師實際的工作流程不熟，需要時請幫我補足這部分的判斷。
- **UI／UX 要以使用者身分實際走過**：老手分析師要連貫、不卡手；新手要看得懂、學得到東西；連小細節（卡片、字級、位置、連續操作）都要顧到。

## 3. 固定規則（不能違反）

- 網站上的儀表板**一律用公開版**（`render_motion.py --public`）：只保留引用的原句，不附完整逐字稿。GitHub Actions 會擋下夾帶完整逐字稿的檔案。
- **市場共識不准猜數字**，維持「待接 TEJ 共識資料」直到接上真實資料。
- **紅漲綠跌**（台股慣例）：上修、優於財測用紅色；下修、低於財測用綠色。
- 不放捏造的支持者、紀錄或付款流程。**小額支持頁只是 12/4 展示用的小彩蛋**，不是真的要收款，按鈕維持「即將開放」。
- `index.html` 必須和 `skill/earnings-call-dashboard/assets/integrated_template.html` 一模一樣：改模板，再複製過去。
- 不下載、不執行來路不明的安裝程式。

## 5. 重要決定與理由

| 決定 | 理由 |
|---|---|
| AI 只寫 `dashboard.json`，讀檔、計分、套版、檢查都交給程式 | 版面每次一樣，AI 沒機會改樣式；符合 TEJ「要穩定的交給 script」 |
| 每項摘要、指引、數字都附原句，由 `check_output.py` 逐條比對 | 「每個數字都查得到出處」是和一般 AI 摘要最大的差別 |
| 能寫成規則又能用程式判斷的瑕疵，規則與檢查一起加 | 只加規則會再犯，兩邊一起加才算補起來 |
| 用 Sonnet 測試，而不是換更強的模型 | TEJ 同仁不一定用最強模型；兩個模型做法不同的地方，就是規則還模糊的地方 |
| 語調詞表自己寫 | tone_analysis 授權不明 |
| 整合儀表板的 `data/` 直接放 HTML、以日期命名 | 照 TEJ 簡報原文；重複收錄會出現同一季兩場 |
| 做成 GitHub Pages 靜態網站，網站只負責瀏覽、搜尋、比較 | 老師同意公開；不需要伺服器與 API 費用，產生儀表板在 Claude 裡完成（選項 A） |
| 網站一律用公開版 | 完整逐字稿要等 TEJ 授權才能公開 |
| 首頁是入口網站，不是單一公司儀表板 | 我要的是「平台」；參考 data.taipei、公開資訊觀測站等 |
| 行事曆預設只顯示 19 個產業的指標公司，其他公司被關注才出現 | 252 家全部列出太雜 |
| 台積電當旗艦，做成「經濟體」頁 | 原本的專區「太無聊」；我想看台積電從創立到現在所有法說會的統整，像分析一個國家的經濟 |
| 台積電歷年資料由 ChatGPT 從台積電 IR 網站蒐集 | TEJ 資料庫只有 2026 年；省 Claude 的 token |
| 議會席次圖改成報紙版面、滑過不改數字 | 原版「數字一直跑、很 AI」 |
| 首頁 3D 長條圖：順序固定、可上下彈動但不能交換位置 | 我的要求；窄螢幕或不支援 WebGL 時退回 2D 版本 |
| 加上內容安全政策（CSP） | 只允許載入本站資源，降低被注入的風險 |
| 小額支持只當彩蛋 | 12/4 展示用；以 TEJ 名義收款需公司同意 |

## 8. 已知的技術眉角

- **改版面**：改 `integrated_template.html`，再 `cp` 成 `index.html`；根目錄的 `integrate.py` 不會幫你複製。
- **Cowork 不能 git push**（2026-11-16 起，只能 clone／fetch）。推送要在自己電腦的終端機執行 `git push origin main`。
- **Cowork 預設不能刪檔**，git 會在 `.git` 留下 `.lock`。已改名成 `.git/stale-*`，不影響使用，可以手動刪除。
- 台積電經濟體是單一檔案、資料全部內嵌（約 530 KB），重建工具在 `tools/tsmc_economy/`。
- 首頁 3D 使用 `vendor/three-lite.js`（three.js 0.187 精簡版，約 560 KB），只在寬度 ≥ 820px、支援 WebGL、沒開「減少動態效果」時載入。
- 網站自動回歸測試是 `tools/site_test.js`（Playwright）。快速切換頁面時偶爾會出現一次 iframe 的 `reqfail`，重跑一次就會通過。
