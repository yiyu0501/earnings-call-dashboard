## 11/4　確定成品長相與視覺

**我的要求**
- 「根據這個簡報，我做出來的成品大概會是怎樣的？我認為 GitHub 看到的好像跟他要求的都不太符合」
- 「我想要參考現實中比較權威、先進的網站的視覺以及交互設計」
- 傳了臺北市資料大平臺的截圖：「我的視覺風格要長這樣」
- 「我要完全相同的視覺風格，然後 logo 用台灣經濟新報的」
- 「我覺得出來的感覺還是跟台北市資料平台有差耶，為什麼」→「讓你用瀏覽器直接打開 data.taipei」
- 給了高解析 TEJ logo：「logo 改成這個比較清晰」，並問交互語言幾分、怎麼精進、還有什麼網站可參考
- 「給我一個 PDF 讓我可以 11/6 跟他們報告」→「只要一個 A4，然後只要文字，然後報告 11/6 要的三個項目」

**決定**
- 用瀏覽器讀 data.taipei 的實際 CSS（字型是系統字型、主色 #1970b8 等），差異主要來自字型、目測色碼、自己加的紅綠色、頁面性質不同。
- 交互語言自評 6/10，主要扣分：篩選要多按一次、沒有模組目錄、搜尋只到第一筆、假按鈕、手機表格太擠、沒有焦點外框。後來在 template 裡補上目錄、上一筆／下一筆、表格左右捲動、焦點外框。
- 推薦參考：GOV.UK Design System、美國 USWDS、data.gov.tw、FRED、公開資訊觀測站。
- 11/6 交付：16 頁規格定案簡報 PDF，以及只有文字的一頁 A4（模組清單、固定格式、版面規則）。

## 11/6　規格書與做成 skill

**我的要求**
- 「可以幫我生成規格書嗎？因為我們要做 skills，所以應該要能夠確定色系、卡片大小、還有字體與大小等細枝末節的事情」
- 「你覺得現在可以做成 skills 了嗎？還是有什麼需要補充或我來確定的」
- 「都可以，然後逐字稿可以是 Word、PDF 甚至 txt、md 等檔案格式」
- 「我現在丟一個逐字稿給你，你可以使用這個 skill 嗎」（台積電 3Q26 英文 PDF）
- 傳了 TEJ 的範例儀表板 HTML 與 2026 逐字稿 xlsx：「這個是他們給我們的範例以及範例逐字稿，你可以參考一下。然後最重要的東西其實是未來期望，你可以把未來期望放高一點。」

**決定**
- 規格書寫成 `references/layout.md`，給 AI 讀，列出所有色票、字級、尺寸、禁止事項與檢查清單。
- **AI 只寫 dashboard.json，程式負責套版**：這樣版面每次一樣，AI 沒機會改 CSS，也符合 TEJ「要穩定的交給 script」。
- 預設值（我說「都可以」）：保留投資評價、語調用詞表計分＋AI 只寫一句說明、檔名 `代號_年份Q季別.html`。
- 語調詞表自己寫，不沿用 tone_analysis（授權不明）。
- 英文逐字稿：內容用繁中，原文保留英文；關鍵數據的數值保留原文寫法以便比對，敘述文字可以換算成中文單位。
- **未來展望升級並移到第二位**：參考 TEJ 範例改成「展望總結＋指引表」，每項有方向、與上一場比較、原文；上限 15 項（TEJ 範例最多 16 項）。
- 投資評價改成 TEJ 的五級；QA 加回答摘要與回答態度（TEJ 的四類）。
- 支援 TEJ xlsx 資料庫格式，並能自動取出同公司上一場做比較。
