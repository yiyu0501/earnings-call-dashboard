# 互動版版面規格

互動版是預設輸出（`scripts/render_motion.py` ＋ `assets/template_motion.html`）。表格版的規格見 `layout.md`。
使用者問到互動版的樣式、或要改 `template_motion.html` 時讀這份。改模板後要同步更新這份檔案，並跑完全部測試案例。

## 1. 原則

- **單檔、離線**：CSS、JavaScript、logo、逐字稿全部內嵌，不載入任何外部資源
- **內容不變、只改呈現**：所有文字都來自 `dashboard.json`；頁面不新增任何 AI 沒寫、程式沒算的內容
- **動態是加分，不是門檻**：系統開啟「減少動態」時，所有動畫、物理效果、橫向捲動自動關閉，內容完整可讀
- **跟著系統的淺色／深色模式**：深色模式用的 logo 由程式自動產生

## 2. 顏色

| 用途 | 淺色 | 深色 |
|---|---|---|
| 主色（連結、數字、正面議題） | `#1970b8` | `#4d9ee0` |
| 深色區塊底（首頁、結論、Q&A） | `#0b2140` | `#0a1a33` |
| 內文 | `#0d0d0d` | `#e8ecf1` |
| 次要文字 | `#717171` | `#9aa6b2` |
| 上修（台股慣例：紅） | `#d62f3c` | `#ff6b74` |
| 下修（台股慣例：綠） | `#14915a` | `#3ccf8e` |

紅綠**只用在上修、下修**，搭配小走勢線圖示，不加底色，避免看起來像按鈕。其餘一律藍與灰。

## 3. 版面順序

1. 首頁（深色）：公司、季別、摘要、比較表（上修／下修 → 維持 → 統計數字，依資料自動選）、評價儀表；沒有評價模組時改單欄
2. 之後依 `modules` 順序排列。「結論＋投資評價」「出席人員＋關鍵字」各合併成一個區塊
3. 自訂模組依 `custom:N` 的位置插入

## 4. 互動

| 元件 | 行為 |
|---|---|
| 評價儀表 | 指針跟著滑鼠轉，下方顯示該級定義；放開後彈回實際評價並顯示判斷依據 |
| 未來展望 | 往下捲時卡片往左移（寬度 960px 以上）；手機改左右滑；可切成「一次看全部」表格、整張複製到 Excel |
| 關鍵數據 | 卡片隨滑鼠傾斜，點一下翻面看原文。變動寫成「由 A……至 B」且 B 等於大數字時，小字只顯示「由 A……至」 |
| 語調分析 | 每個詞標次數，點下去在逐字稿標出每一處，可逐處跳轉 |
| Q&A | 依回答態度篩選、展開看回答與原文 |
| 關鍵字 | 會落下、可拖曳丟擲的球，大小依次數 |
| 報告稿 | LINE 同步、組內摘要、研報重點、自己挑；可直接修改後複製，問候語依時間自動加上 |
| 看上下文 | 開啟完整逐字稿並跳到該句；修正項目可看上一場原文 |
| 怎麼算的 | 評價五級標準、本場判斷依據、語調算法與完整詞表 |

## 5. 副標題語氣

說明資料的副標題用正式書面語，並寫明比較基準與判斷依據，例如：

> 比較基準：2026-05-19 法說會（第一季）。本場未見上修或下修；下列指引判定為維持，惟前次未揭露可對照之數值，係依本場管理層陳述判定。

告訴使用者怎麼操作的提示維持白話，例如「點卡片翻面看原文」。

## 6. 檢查

`check_output.py` 會自動判斷是互動版，檢查：無外部資源、內嵌資料可解析、未使用瀏覽器儲存空間、圖片有替代文字、有「跳至主要內容」、有減少動態設定，以及 375px 寬度下沒有橫向捲軸。
