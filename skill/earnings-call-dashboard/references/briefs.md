# 報告稿 briefs 寫作規範

互動版右上角「報告稿」有三種現成的稿，使用者按一下就能複製、小改後貼給同事。它們代表 TEJ 對外的口吻，所以每一場、每一家公司都要像同一個人寫的：結構固定、用詞固定，只有內容依場次不同。

`check_output.py` 會檢查格式與數字，下面標 🔒 的規則沒過就不能交付。

## 目錄

1. 共通規則
2. line：LINE 同步
3. memo：組內摘要
4. report：研報重點
5. 用詞對照
6. 禁用語

---

## 1. 共通規則

- 🔒 **每個數字都要出自儀表板裡已查證的內容**（摘要、指引、關鍵數據、QA、語調分數、題數）。程式會核對；億與 billion 的換算可以接受（402 億美元＝US$40.2 billion）
- 只寫逐字稿裡有的事。報告稿是「整理」，不是「分析」：不寫股價、目標價、買賣建議
- 用「事實＋數字」取代形容詞：寫「營收 402 億美元，落在財測高標」，不寫「營收表現亮眼」
- 管理層的判斷要標出是誰說的：「管理層說 AI 需求比之前講的更強」，不寫成既定事實
- 說法不一致、資料不完整時要直說：「講稿說 400 億美元，Q&A 說 1,000 億美元，說法不一致」「逐字稿只收錄後段」
- 數字與中文之間空半形空格：「402 億美元」「EPS 5.66 元」
- 日期寫「7/16」（line、memo）或「2026/7/16」（report 標題）；不知道日期就省略，不要留空格或寫「日期未提及」以外的猜測
- 🔒 不可出現連續兩個空格

## 2. line：LINE 同步

給同事快速同步用。頁面會依打開時間自動在最前面加「各位同事早安／午安／晚上好，」，所以 🔒 **不要自己寫問候語**。

- 第一行固定：「幫大家同步一下{公司} {月/日} 法說會的重點：」；逐字稿不完整時在冒號前補一句括號說明
- 不知道日期時寫「幫大家同步一下{公司}這場法說會的重點：」，不要留下空白
- 🔒 接著 3–5 條「1. 2. 3.」編號條列，每條一句，40 字以內
- 順序：本季結果 → 下一季指引 → 上修／下修 → 管理層對前景的說法或最大變數
- 🔒 全文 80–260 字

**好的範例（台積電）**
```
幫大家同步一下台積電 7/16 法說會的重點：
1. Q2 營收 402 億美元，落在財測高標。
2. Q3 營收指引 446–458 億美元（中值季增 12%），毛利率 65–67%。
3. 全年美元營收成長從 30% 以上上修到略高於 40%。
4. 資本預算從約 560 億美元上修到 600–640 億美元，另宣布追加亞利桑那投資。
5. 管理層說 AI 需求比之前講的更強；消費性市場受零組件漲價影響。
```

**不好的範例**
```
各位早安！台積電這次法說會表現亮眼，AI 需求強勁，全年展望樂觀，值得期待！
```
問題：自己寫了問候語、沒有條列、沒有數字、用了禁用語、把評價寫成事實。

## 3. memo：組內摘要

會議紀錄或組內討論用，先給結論再給細節。

- 第一行固定：「【{公司} {年} Q{季} 法說會摘要】」
- 🔒 第二段是一段總結，2–3 句：整體方向＋主因＋要留意的事。以「整體來看，」開頭
- 🔒 空一行後寫「重點：」，接 4–5 條編號條列，每條以「主題：」開頭（本季、指引、上修、Q&A、要留意／待確認）
- 🔒 全文 200–520 字

**好的範例（儒鴻）**
```
【儒鴻 2026 Q2 法說會摘要】
整體來看，營運穩健但上修空間有限。營收創 16 季新高、毛利率回到 30% 以上，但舊款產品下單比重偏高，毛利率目標沒有上修，管理層對下半年的說法是審慎樂觀。

重點：
1. 本季：營收 100.85 億元，年增 3.79%；毛利率 30.01%，上升 4.36 個百分點；EPS 5.66 元。
2. 成衣：營收 70.85 億元，年增 11.19%，新客戶雙位數成長；針織布因內轉比例提高而年減。
3. 指引：毛利率內部目標維持 28%–32%，延到年底再檢視；每月營收 30 億元以上目標審慎樂觀；能見度約六個月。
4. Q&A：21 題中，第三季原料衝擊會收斂；關稅退款、價格轉嫁、資本支出金額都沒有正面回答。
5. 要留意：存貨增至約 63 億元、週轉天數 112 天；台幣升值對第三季匯兌有壓力。
```

## 4. report：研報重點

寫報告時的底稿，最完整、最像正式文件。

- 第一行：「{公司} {年} Q{季} 法說會重點（{年/月/日}）」
- 🔒 空一行後寫「結論：」一句話
- 接分段：「一、本季結果」「二、指引與修正（前次 → 本次）」「三、Q&A 觀察」「四、風險」，沒有內容的段落省略，項目用「・」
- 指引修正寫「前次 → 本次」，例如「2026 資本預算：約 US$56B → US$60–64B」
- Q&A 觀察要寫回答態度分布（正面幾題、保守幾題……）與提問單位
- 有語調分數時最後一行寫「語調：管理層講稿 +0.92、Q&A +0.49（範圍 −1 到 +1）」
- 最後一行固定：「資料來源：TEJ 逐字稿資料庫，{公司} {年/月/日} 法說會」（非 TEJ 來源就寫檔名）

**好的範例（台積電）**
```
台積電 2026 Q2 法說會重點（2026/7/16）

結論：全年營收成長與資本預算同步上修，成長動能集中在 AI；主要變數是消費性需求與設備漲價。

一、本季結果
・Q2 營收 US$40.2B，位於財測高標
・先進製程（7 奈米以下）占晶圓營收 77%，2 奈米占 3%
・HPC 季增 20%，占營收 66%；智慧型手機季減 4%，占 22%
・現金及有價證券 NT$3.5 兆；存貨天數 87 天，增加 7 天（N2 爬坡）

二、指引與修正（前次 → 本次）
・2026 全年營收成長（美元）：30% 以上 → 略高於 40%
・2026 資本預算：約 US$56B → US$60–64B
・未來三年資本支出：顯著高於過去三年 → 更顯著提高（未給數字）
・AI 需求：2024–2029 年複合成長率約五成五至五成九（mid-to-high 50s）→ 更強（未給新數字）
・Q3：營收 US$44.6–45.8B，毛利率 65–67%，營益率 56–58%

三、Q&A 觀察
・22 題中，正面 9 題、保守 5 題、防禦性 3 題、避重就輕 5 題
・提問券商：UBS、Morgan Stanley、Macquarie、JPMorgan、Citi、Bank of America、Deutsche Bank、Goldman Sachs、凱基
・長期數字一律不量化
・先進封裝產能吃緊，已限制客戶成長，歡迎替代方案分擔
・定價：不會大幅漲價，以毛利足以支撐長期擴產為原則

四、風險
・消費性與價格敏感市場受零組件漲價衝擊
・設備漲價帶來成本壓力
・亞利桑那追加投資金額，講稿與 Q&A 不一致（400 億 vs 1,000 億美元）

語調：管理層講稿 +0.92、Q&A +0.49（範圍 −1 到 +1）
資料來源：TEJ 逐字稿資料庫，台積電 2026/7/16 法說會
```

## 5. 用詞對照

| 寫這個 | 不寫這個 |
|---|---|
| 季增、年增 | 環比、同比、QoQ、YoY（原文引用除外） |
| 百分點 | 個 %、pp |
| 上修、下修、維持 | 調升、調高、上調（指引修正一律用這三個） |
| 管理層說、管理層表示 | 公司認為、我們覺得 |
| 審慎樂觀（照管理層原話時） | 謹慎樂觀 |
| 億元、億美元 | 億、E（要寫幣別） |
| 未給數字、未量化 | 沒說、不知道 |

## 6. 禁用語

🔒 以下用語出現在摘要、結論、展望總結或報告稿時，程式會擋下，請改寫成具體的事實或數字：

令人振奮、表現亮眼、亮眼、驚豔、值得期待、值得關注、不容小覷、毋庸置疑、綜上所述、總而言之、值得一提的是、強勢回歸、全面爆發、一片看好

清單之外也避免：誇飾的形容詞、驚嘆號、「不僅……更……」這類修辭句型。
